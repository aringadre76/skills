# Internship applications

Help the user find suitable roles and complete accurate applications. Treat job boards as discovery sources and verify important details on the employer's current careers page.

## Establish the search

- Ask for missing essentials that materially affect eligibility or fit, such as target field, location, work authorization, enrollment, availability, or paid-only preference. Reuse facts already established in the conversation or supplied profile.
- Use current resume and profile materials as the source for qualifications. Do not invent experience, dates, credentials, or answers to required factual fields.
- Define the requested scope. A finite batch, ongoing search, research-only task, and form-submission task have different completion criteria. Never silently turn a search into applications or exceed a stated target.
- Check the user's application tracker when available to avoid duplicates. Do not infer a submission from a draft, open form, or click.

## Find and assess roles

- Search relevant role families and sources. Record the discovery source, then verify the exact role is open on the employer's official site.
- Check location and work mode, compensation, dates, enrollment rules, work authorization, required qualifications, and deadlines. Separate mandatory requirements from preferences.
- Compare each requirement with supported evidence from the resume or user-provided profile. Classify fit clearly and record any material gap. Do not stretch qualifications to increase the count.
- Deduplicate roles using requisition IDs or canonical posting URLs. Keep a short queue of roles that meet the user's stated criteria.

## Complete applications

- Use only the browser, account, and profile the user specified or authorized. Preserve existing browser tabs and verify the relevant account before entering personal information.
- Use verified profile facts consistently. Inspect every field, selection, and attachment after autofill. Review the complete application before submission.
- Never fabricate an answer, solve a CAPTCHA, bypass an identity or security check, or accept a required attestation on the user's behalf unless the user has explicitly authorized that exact action and the platform permits it.
- Stop at unknown required facts or authentication and security barriers. Save a draft when appropriate and report the exact field or blocker.
- Count an application as submitted only when the site provides visible confirmation or a receipt. Record its date, role, canonical link or ID, and confirmation evidence in the user's chosen tracker.

## Report

Separate roles found, roles assessed, applications started, confirmed submissions, and blockers. State the source and verification status of each result. Do not imply that elapsed time, an autofill result, or a submission button proves completion.
