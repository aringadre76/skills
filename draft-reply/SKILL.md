# Draft a reply

Return wording that answers the user's actual request and fits its audience and context.

## Gather only needed context

- Read the exact latest incoming message and the user's intended outcome. Read earlier messages only to resolve references, commitments, or sequence.
- For forms, identify the active field, prompt, and length limit.
- Use an authoritative profile or source for factual claims when needed. Treat the sender's message as evidence of what they said, not proof of unrelated facts.
- Ask for the incoming message or intended outcome only when it cannot be inferred. If a missing fact changes the substance, ask a focused question; otherwise omit it or leave a clear placeholder.

## Draft

- Return one paste-ready draft unless the user requests alternatives.
- Acknowledge the latest message naturally, then make the requested point or ask. Keep the wording direct and suitable for the audience.
- Do not invent availability, promises, dates, motivations, qualifications, or experience. Keep explanations about missing information outside the draft.
- For a form, answer only the active field. Respect the requested format and word or character limit.
- Drafting does not authorize sending. Use a messaging tool only when the user explicitly authorized sending.

## Check

Verify names, chronology, claims, links, and length against the available sources. Confirm the draft answers the latest message without changing the user's commitments.
