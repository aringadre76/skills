# Prepare for class

Build a lesson or review from the learner's actual course materials and requested scope.

## Establish scope and sources

- Infer the course and topic from the request and supplied material. Ask one focused question when multiple courses or topics remain plausible.
- Read the course instructions and the relevant lecture, demo, notebook, assignment, or syllabus sections. Follow the course's folder map when present.
- Identify the instructor's materials separately from notes, summaries, and generated study aids. If a source is inaccessible or unreadable, state the coverage limit.
- For assessed work, determine which methods and notation the course has covered by the relevant cutoff. Do not introduce later methods unless asked.
- For date-sensitive questions such as "next class," verify the current calendar or course announcement if available; label local syllabus dates as unverified when they are the only source.

## Teach and practice

- Match the requested format: briefing, worked lesson, exam review, or interactive practice.
- Define unfamiliar terms and symbols before using them. Show the setup, rule, intermediate steps, result, and interpretation.
- Use clear examples that follow the instructor's notation and covered methods. Cite the actual lecture, section, or page used.
- In interactive practice, give one problem and wait for the learner's attempt before showing the solution. Keep questions and answers separate in standalone guides.
- If asked to cover every slide or section, account for each one and mark unreadable content rather than silently summarizing around it.

## Check the result

Compare the lesson with the requested topics. Recalculate worked answers and run example code when runtime behavior matters. Distinguish a completed explanation from evidence that the learner has mastered it.
