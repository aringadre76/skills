# Prepare for an interview

Make practice specific to the role and interview stage while grounding claims in the person's actual experience.

## Establish context

- Read the supplied job description, interview format, exercise, and current practice notes. Use a current resume or profile only when tailoring requires it.
- Infer role, language, and stage from the session. Ask one focused question if a missing detail changes the exercise. A named topic is enough to begin a useful drill.
- Verify current company-specific claims from official sources when they matter. Do not infer present interview status from old notes.
- Check the previous exercise before claiming a new drill is novel. Keep intentional bugs and hidden solutions protected until requested.

## Practice

- For interactive rehearsal, ask one appropriately sized question or give one drill, then wait for the attempt.
- Give targeted feedback tied to the answer, with a clear next step. Explain prerequisites in manageable increments.
- Ground behavioral stories in supported experience. Separate the person's contribution from team outcomes, and ask for missing results rather than inventing metrics.
- For a full preparation plan, cover the requested topics and separate practice prompts from sample answers.
- Create coding artifacts only in the requested location. Clarify an unspecified save destination before writing durable files.

## Check the result

Check the exercise against the requested role, format, difficulty, and prior work. Run a harness when executable code is part of the deliverable. Distinguish a verified exercise from the person's performance; practice is not complete until an attempt is observed.
