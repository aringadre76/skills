# Agent Skills

Reusable skills for AI coding assistants. Each folder contains a standalone `SKILL.md` that explains when and how to use a workflow. Adapt the guidance to your tools, project instructions, and local policies before use.

## Skills

| Skill | Use it for |
|---|---|
| [continual-learning](continual-learning/SKILL.md) | Reviewing conversations and updating durable assistant memory |
| [codex-continual-learning](codex-continual-learning/SKILL.md) | Reviewing transcripts across Codex, Cursor, and OpenCode |
| [draft-reply](draft-reply/SKILL.md) | Drafting concise replies and application responses |
| [internship-applications](internship-applications/SKILL.md) | Finding and applying to suitable internship roles |
| [learn-commit-push](learn-commit-push/SKILL.md) | Combining memory maintenance with reviewed Git publication |
| [prepare-for-class](prepare-for-class/SKILL.md) | Learning from course materials and practicing concepts |
| [prepare-for-interview](prepare-for-interview/SKILL.md) | Interview rehearsal and coding practice |
| [research-purchase](research-purchase/SKILL.md) | Comparing products using current listings and constraints |
| [troubleshoot-hardware](troubleshoot-hardware/SKILL.md) | Diagnosing computer, device, and network problems |

These are starting points, not a substitute for checking facts, current sources, project rules, and user authorization. Review each skill before using it with sensitive information or consequential actions.
